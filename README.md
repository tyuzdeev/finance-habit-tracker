# 💰 Finance & Habit Tracker (Vanilla JS)

Легковесное веб-приложение (Single Page Application) для отслеживания личных финансов и ежедневных привычек. 

Проект разработан для демонстрации уверенных навыков работы с чистым JavaScript (DOM API) и браузерным хранилищем без использования тяжелых фреймворков и баз данных.

## 🚀 Функционал
- **Учет доходов и расходов:** Добавление транзакций (положительные числа — доходы, отрицательные — расходы).
- **Авто-калькуляция:** Баланс пересчитывается автоматически при добавлении или удалении записи.
- **Трекер привычек:** Отдельный счетчик для поддержания ежедневной рутины (например, программирование).
- **LocalStorage:** Все данные мгновенно сохраняются в память браузера. При обновлении страницы или закрытии вкладки ничего не теряется.

## 🛠 Стек технологий
- **HTML5** — семантическая структура
- **Tailwind CSS** — стилизация, темная тема (Dark Mode), адаптивность под мобильные устройства
- **Vanilla JavaScript (ES6)** — вся логика приложения (обработка событий, массивы, `JSON.parse` / `JSON.stringify`)

## 💡 Особенности реализации в коде
- Отказ от `innerHTML` при добавлении данных с формы в пользу безопасного создания узлов через `document.createElement()`.
- Использование классических циклов и `splice` для работы с индексами массива истории.
- Обработка жизненного цикла через `DOMContentLoaded`.

## 💻 Как запустить
Проект не требует установки пакетов, Node.js или сборщиков. 

1. Склонируйте репозиторий:
   ```bash
   git clone [https://github.com/tyuzdeev/finance-habit-tracker.git] (https://github.com/ВАШ_НИК/finance-habit-tracker.git)
   ```
2. Просто откройте файл `index.html` в любом современном браузере.
